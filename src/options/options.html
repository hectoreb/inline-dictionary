Merriam-Webster (inglés)

Para buscar definiciones en inglés necesitas una API key gratuita de dictionaryapi.com. Sin esta key, la extensión sigue funcionando — solo en español (Wikcionario).

Idioma por defecto

Si está en "Auto", la extensión detecta el idioma de cada palabra. Si no, usa el idioma que elijas aquí.

Cache

Las definiciones se guardan localmente para acelerar lookups repetidos. Puedes limpiarla aquí.
